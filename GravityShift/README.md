# Gravity Shift — 3D-игра с переключением гравитации

## Описание

**Gravity Shift** — это 3D-игра от первого лица, где вы управляете субъектом в лаборатории гравитационных исследований. Ваша задача — пройти через 6 зон с препятствиями, переключая направление гравитации.

Вы можете "ходить" по стенам и потолку, обходя ямы, лазеры, движущиеся блоки и другие ловушки.

---

## Требования

- **Unity 2022.3 LTS** или новее (бесплатная Personal версия)
- Скачать: [Unity Hub](https://unity.com/download)

---

## Как открыть проект

1. Скачайте и установите **Unity Hub**
2. В Unity Hub установите **Unity 2022.3** (любая подверсия)
3. Нажмите **"Add"** (Добавить) в Unity Hub
4. Выберите папку `GravityShift` (эту папку)
5. Unity откроет проект и импортирует пакеты (подождите 1-2 минуты)
6. В окне **Project** откройте `Assets/Scenes/MainScene.unity`
7. Нажмите **Play** (▶) — и играйте!

---

## Управление

| Клавиша | Действие |
|---------|----------|
| **WASD** | Движение |
| **Мышь** | Осмотр |
| **Q** | Переключить гравитацию влево |
| **E** | Переключить гравитацию вправо |
| **Space** | Прыжок |
| **Shift** | Бег |
| **Escape** | Пауза |
| **R** | Рестарт уровня |

---

## Зоны

1. **Учебный коридор** — простые ямы, обучение механике
2. **Шахта** — вертикальный подъём через переключение гравитации
3. **Куб** — путь по всем 4 поверхностям кубической комнаты
4. **Лабиринт Эшера** — головоломки с кнопками на стенах/потолке
5. **Нулевая точка** — быстрые препятствия, толкающие стены
6. **Финальный побег** — всё вместе + ограниченные переключения

---

## Как добавить звуки

1. Перетащите `.mp3` или `.wav` файлы в `Assets/Resources/`
2. Выберите объект **AudioManager** на сцене
3. В Inspector перетащите аудио файлы в нужные поля

---

## Как настроить

В Unity Inspector вы можете настроить:

- **Чувствительность мыши** — на объекте Player → FirstPersonController
- **Скорость/высоту прыжка** — там же
- **Кулдаун гравитации** — Player → GravityController
- **Скорость/паузы препятствий** — на каждом препятствии
- **Номер зоны** — на GameBootstrapper → LevelBuilder → zoneToLoad

```
│   └── Resources/                   — Для ваших аудио файлов
├── Packages/manifest.json           — Зависимости Unity
└── ProjectSettings/                 — Настройки проекта
```

## Известные особенности

- Весь уровень создаётся программно при запуске (нет готовых моделей)
- Графика минималистичная (примитивы Unity + свечение + частицы)
- Стиль: sci-fi лаборатория (как Portal)
- Для смены зоны измените значение `zoneToLoad` на объекте GameBootstrapper
